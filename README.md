# Волк ловит яйца — автономная HTML5-игра

Игра на JavaScript, Canvas 2D и Web Audio API. Устанавливается на главный экран Android/iPhone как PWA. После однократного сохранения на телефоне игра запускается без интернета, Telegram, компьютера и работающего сервера. Нативных APK/IPA в проекте нет.

## Установка на телефон

Используйте HTTPS-адрес **с этой версией файлов**. Изменения из PR становятся доступны на обычном адресе GitHub Pages только после их объединения и публикации. Открытие страницы самого репозитория или PR игру не устанавливает.

### Android (Chrome)

1. Откройте опубликованный HTTPS-адрес игры в обычной вкладке Chrome, вне Telegram.
2. Дождитесь надписи **«Готово к игре без интернета»**: сохранены страница, код, оформление, все четыре позиции волка и иконки.
3. Нажмите «Установить», если кнопка появилась, либо **⋮ → Установить приложение / Добавить на главный экран → Установить**. Название пункта зависит от версии Chrome.
4. Откройте игру через новый значок один раз с сетью и снова дождитесь готовности.
5. Закройте игру, включите авиарежим (выключите также Wi-Fi) и запустите её через значок. Проверьте все четыре курицы, звук и повторную игру.

### iPhone (Safari)

1. Откройте опубликованный HTTPS-адрес игры в обычной вкладке Safari, вне Telegram и приватного режима.
2. Дождитесь **«Готово к игре без интернета»**.
3. Нажмите **Поделиться → На экран Домой**. Если есть переключатель **«Открывать как веб-приложение»**, включите его. Нажмите **Добавить**.
4. Откройте значок игры один раз с сетью и дождитесь готовности именно в этом окне: данные установленного приложения могут отличаться от вкладки Safari.
5. Закройте игру, включите авиарежим с выключенным Wi-Fi и запустите её через значок.

Первое получение файлов требует сети до HTTPS-сервера. Дальнейшая игра и повторный запуск работают локально. Обычная ссылка `http://192.168.…` на компьютер в Wi-Fi и открытие `index.html` через «Файлы» не являются способом установки этой PWA, в том числе на iPhone. Для установки через локальную сеть нужен HTTPS с сертификатом, которому доверяет телефон; обход проверки сертификата не заменяет доверие.

Не удаляйте данные сайта/приложения: там хранится автономная копия. Браузер или ОС также могут удалить её при очистке или нехватке места. Игра запрашивает сохранение данных, если браузер поддерживает это, но не может гарантировать согласие ОС. После удаления данных потребуется снова открыть приложение с сетью. Индикатор проверяет наличие каждого ресурса; при неполной загрузке готовность не объявляется. Недостающие файлы восстанавливаются при следующем открытии с сетью.

Официальные инструкции: [Chrome на Android](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid), [Safari на iPhone](https://support.apple.com/guide/iphone/turn-a-website-into-an-app-iphea86e5236/ios), [требования к устанавливаемой PWA](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable).

## Управление и звук

Нажимайте прямо на куриц: 1 — слева сверху, 2 — справа сверху, 3 — слева снизу, 4 — справа снизу. Первое нажатие начинает игру. Ловля повышает счёт, каждые 10 очков растёт уровень; три промаха завершают игру. Для новой партии снова нажмите на курицу.

Кнопка «Пауза» приостанавливает игру. При сворачивании или уходе со страницы игра также ставится на паузу; для продолжения нажмите на курицу или «Продолжить». Счёт и текущая партия сохраняются только пока страница остаётся открытой; после закрытия начинается новая партия. Настройки звука сохраняются на устройстве, если браузер разрешает хранилище. Запрет хранилища не мешает играть.

Звуки синтезируются на телефоне без аудиофайлов. Для начала звука требуется первое касание; также проверьте громкость и беззвучный режим телефона. Внешние шрифты, CDN, API, аналитика и Telegram SDK не загружаются. Telegram больше не нужен для запуска; страница может открываться в его браузере, но установку выполняйте через Chrome/Safari.

## Сборка и проверка

Нужен Node.js 22 или новее. Пакеты нужны только разработчику для браузерных проверок, на телефоне они не устанавливаются.

```sh
npm ci
npm run build
npx playwright install chromium webkit
npm test
npm run preview
```

Предпросмотр на этом компьютере: `http://localhost:4173/wolf-game/` (также поддерживается `/`). Для HTTP localhost браузер разрешает service worker. На смартфоне `localhost` означает сам смартфон.

`npm run build` без внешних библиотек собирает каталог `dist/` и обновляет отслеживаемый `sw.js` в корне. Версия автономного кеша вычисляется из содержимого всех ресурсов и шаблона service worker. После изменений повторите сборку и включите обновлённый `sw.js` в коммит. В сборку входят только игровые файлы; старые неиспользуемые изображения/заглушки остаются вне неё. Иконки можно пересоздать командой `node scripts/icons.mjs`.

Браузерные тесты проверяют Chromium с параметрами Android и WebKit с параметрами iPhone: повторный запуск без сети, все четыре изображения, счёт/уровень/жизни/рестарт, паузу, звук и сохранение настроек, запрет хранилища, размеры экрана, неполную установку и восстановление отсутствующего ресурса. Это автоматизация настольных движков с мобильными параметрами, **не доказательство установки на физических телефонах или слышимости звука на них**. На реальных Android/iPhone выполните шаг 5 установки и проверьте сворачивание/возврат, портретный и альбомный режимы. CI выполняет сборку и те же тесты, сохраняет `dist/` как артефакт, но ничего не публикует.

## Публикация и обновление

Для существующего GitHub Pages с источником **main / root** достаточно включить в публикацию корневые `index.html`, `styles.css`, `game.js`, `offline.js`, `sw.js`, `manifest.webmanifest`, `.nojekyll` и каталог `assets/`. Для другого статического HTTPS-хостинга загрузите содержимое `dist/` целиком. Сервер должен возвращать JavaScript для `sw.js` с корректным MIME-типом, без авторизации и перенаправления на HTML. Пути относительные, поэтому установка поддерживает как корень сайта, так и `/wolf-game/`.

Сам PR не переключает опубликованную игру. Проверки намеренно не меняют настройки Pages и не выполняют развёртывание. Архив `dist/` также нужно разместить на HTTPS-сервере для установки на телефон; распаковка архива в «Файлы» на iPhone этого не заменяет.

Новая версия сначала сохраняется целиком. Если загрузка любого ресурса не удалась, старая установленная версия продолжает работать. Обновление активируется после закрытия всех окон/вкладок со старой версией, чтобы не подменять ресурсы посреди партии. Откройте игру с сетью, затем закройте все её окна и откройте снова. Настройки звука при этом остаются.

## Настройка

Сложность задаётся в объекте `GAME` в `game.js`: `baseTravelTime`, `minTravelTime`, `baseSpawnEvery`, `minSpawnEvery`. Отладка зон нажатия включается параметром `?debug`, который работает и при автономном запуске. Игровые кадры — локальные WebP 960×720, Canvas использует исходные координаты 1448×1086.
